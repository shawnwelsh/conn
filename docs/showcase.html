The real deck, rendered by Conn's own tile engine: a Bash approval on the invoicing console. It waits while you decide with one press — and you can deny and say why by voice.

What it does

Everything works from the browser deck; a Stream Deck is just nicer buttons for the same bridge.

🟦

Live status, per session

Every Claude Code session claims a key and shows idle · thinking · waiting · done · error — as a colour and a shape, readable at a glance across a whole grid.

🟠

One-press permissions

A permission request morphs the keys into Allow / Always-allow / Deny. The on-screen dialog waits; you never hunt for the right window.

📋

Approve plans

Plan mode gets its own panel. Approve from the deck and the console drops into auto mode — routine work runs, only the risky stuff comes back.

🔢

Answer questions

When a session asks a multiple-choice question, the options become keys. Answer the whole ask from the deck.

🎙

Talk to any session

Tap the mic, speak, and the transcript lands in the targeted console. Even deny a tool call by saying why — the reason reaches Claude.

🌱

Spawn in fresh worktrees

New opens a session in its own git worktree on a deck/<codename> branch — parallel work never shares a tree, and the codename is the label.

↩️

Focus that returns

Answer an interruption from another session and the deck hands focus back to what you were working in. An answer, not an answer plus a re-select.

🛟

Fail-open by design

Bridge down, timed out, or no deck connected? Claude Code's normal dialog appears. Conn never turns its own failure into an automatic allow.

🖥️

Browser or hardware

The web deck at 127.0.0.1:3711 is a first-class client — the same tiles and gestures. Point a Stream Deck at it when you want the buttons.
